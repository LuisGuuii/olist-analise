# Análise de E-commerce Olist

Projeto de análise de dados com SQL, Python e Power BI, usando o dataset
público Brazilian E-Commerce (Olist), disponível no Kaggle.

## Pergunta central
Atrasos na entrega reduzem a satisfação dos clientes? Onde o problema se concentra?

## Estrutura
- `sql/`: consultas de exploração e de análise
- `carregar_dados.py`: carrega os CSVs em um banco SQLite
- `dados/`: arquivos CSV (não versionados)
